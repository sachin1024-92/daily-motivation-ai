# Page upgrade kit (apply in ~2 min per Page)

Facebook doesn't allow the connected tool to change a Page's profile, cover or bio, so apply these by hand.
Facebook app → switch to the Page → **Edit** (pencil icon).

## 4KEdits
- **Profile picture:** `4kedits_profile.png`
- **Cover photo:** `4kedits_cover.png`
- **Bio:** 🎬 Edit like a pro: one video-editing tip a day. CapCut • Premiere • DaVinci • Reels tricks. Follow & save!
- **Category:** Video Creator (add *Education* as a second category)
- **Action button:** *Follow* (or *Send message* if you take editing orders)
- **Username:** `@4keditsdaily` (or similar if taken)
- **Pin to top:** the "Which Editor?" poll post when it goes live

## Every Page, once
- Turn on **Professional mode** (Page → ⋯ → Turn on professional mode) to get the dashboard and reach tools.
- **Invite friends** (Page → ⋯ → Invite friends) and invite everyone. The first 100 followers unlock reach.
- Share each Reel to your own profile, your Story and 2–3 relevant Groups.
